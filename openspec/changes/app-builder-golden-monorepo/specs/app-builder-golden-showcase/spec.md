# Delta for App Builder Golden Showcase

## ADDED Requirements

### Requirement: Canonical Committed Showcase

The repository MUST maintain a committed Todo Golden showcase generated by the same public command as consumer generation. It MUST include canonical provenance and a regeneration command, and MUST be excluded from root Nx and pnpm graph discovery.

#### Scenario: Verify showcase provenance

- GIVEN the committed showcase
- WHEN a maintainer inspects its provenance
- THEN it MUST identify the public regeneration command and canonical inputs

#### Scenario: Exclude the showcase from root discovery

- GIVEN root Nx and pnpm discovery execute
- WHEN the showcase exists
- THEN it MUST NOT appear as a root workspace project or package

### Requirement: Showcase Drift Detection

CI MUST regenerate the showcase through the public command and compare canonical generated output to the committed showcase. Drift MUST fail CI with actionable canonical evidence and MUST NOT silently rewrite the committed artifact.

#### Scenario: Detect showcase drift

- GIVEN committed showcase output differs from canonical regeneration
- WHEN CI verifies it
- THEN CI MUST fail and report the mismatch

#### Scenario: Verify a matching showcase

- GIVEN canonical regeneration equals the committed showcase
- WHEN CI verifies it
- THEN CI MUST pass without modifying the repository
